BIZYNQ website - static HTML/CSS/JS (no build step)

SETTINGS:  js/config.js  (WhatsApp, phone, email, address, hours, Calendly, Google Analytics ID)
DOMAIN:    search all files for "www.bizynq.in" and replace with your real domain
           (canonical tags, sitemap.xml, robots.txt). Do this before launch.
TEAM:      about.html contains a commented-out "Founders and team" section. Remove the
           <!-- and --> markers around it when you have names and photos.
BLOG:      copy blog/article-template.html, rename, edit, remove the noindex line, link from blog.html.
HOSTING:   upload this folder to GitHub, connect to Netlify, point the GoDaddy domain to Netlify.
